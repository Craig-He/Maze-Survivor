# Maze-Survivor
Maze Survivor is a two player maze game, in which the tagger chases the runner around a maze with no exits that is generated using Prim’s algorithm. This was for my Computer Science Coursework. The project is coded using Pyhton

The project write up contains the Analysis, Design, Technical solution, Testing and Evaluation of the project
